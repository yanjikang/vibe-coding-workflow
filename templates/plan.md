# 开发计划（plan.md）

> **用法**：窗口 1 需求对齐完成后，让 AI 依据对话内容填写本模板；此后它既是任务清单，也是任务模式（Step 07）的输入。
> 勾选框随进度实时更新，`progress.md` 只记录"当前窗口"状态，全局计划以本文件为准。

## 1. 产品概述

- **一句话定位**：〔例：一个帮自由职业者自动整理发票的 Web 应用〕
- **目标用户**：〔谁会用它，在什么场景下用〕
- **核心交互形态**：〔例：单页应用 / 左右分栏 / 移动端优先〕
- **明确不做的（范围外）**：〔防止 AI 过度发挥，逐条列出〕

## 2. 技术栈锁定（Step 02 产出）

| 层 | 选型 | 版本 | 锁定理由 |
|----|------|------|----------|
| 语言 | 〔TypeScript〕 | 〔5.x〕 | 社区语料丰富 |
| 框架 | 〔React / Vue〕 | 〔18.x〕 | 主流成熟，防幻觉 |
| 构建 | 〔Vite〕 | 〔5.x〕 | |
| UI 库 | 〔-〕 | | |
| 状态/数据 | 〔-〕 | | |
| 存储/后端 | 〔-〕 | | |

> 原则：只选社区语料最丰富的主流框架并**固定依赖版本**；冷门库与过新 API 是 AI 幻觉重灾区。

## 4. 每个模块的"完成定义"（DoD）

一个模块只有同时满足以下条件才算完成，才允许在 `progress.md` 标记 ✅：

1. 运行预览无控制台报错，交互符合预期（Step 09~10）
2. 已 Git Commit 建立安全存档点（Step 14）
3. `progress.md` 已更新，供下一个窗口接力（Step 15）
